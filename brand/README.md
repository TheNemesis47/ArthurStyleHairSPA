# brand/ — Materiali del brand Arthur Style

Qui vanno i materiali forniti dal cliente o prodotti per Instagram. Servono per il design del sito, del pannello e dell'app.
Domande collegate: Q05, Q06 in [docs/17](../docs/17-domande-aperte.md).

| Cartella | Contenuto atteso | Note |
|----------|------------------|------|
| `logo/` | Logo in **SVG** (positivo, negativo, monogramma), PNG ad alta risoluzione | Area di rispetto, dimensioni minime |
| `palette.md` | Colori HEX/RGB con il loro ruolo (primario, accento, sfondo, testo) | Verificheremo il contrasto WCAG AA |
| `fonts/` | File dei font **con licenza web e app** (WOFF2) + licenze | I font vanno self-hosted (niente CDN Google: vedi docs/14) |
| `instagram/` | Template ed esempi dei post già pubblicati | Per allineare tono e stile |
| `photos/` | Foto del salone, di Arturo, dei lavori | Per le foto dei clienti: **liberatoria** obbligatoria (docs/14 §8) |
| `voice.md` | Tono di voce, parole chiave, parole da evitare | IT + EN |

> Non inserire qui dati personali dei clienti o documenti con dati sensibili.
